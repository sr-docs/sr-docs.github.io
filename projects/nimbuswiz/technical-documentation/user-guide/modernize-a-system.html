Modernize a system

When you have a recommendation, use the Upgrade Profiles page to simulate the change before you apply it.

The simulation runs four safety checks without touching the system: dependency compatibility, disk space, backup state, and quirk conflict detection. All four must pass before the apply buttons become active. That gate can't be bypassed.

Before you begin​

To access the Modernize page, you need a system with a passing assessment. The Upgrade Profiles page is accessible from the Modernization Advisor after you've reviewed a recommendation.

Select an upgrade profile​

Pick the profile that matches your goal.

ProfileWhat it doesRisk
StableConservative upgrade. Prioritizes uptime and compatibility. Minimal disruption.Low
PerformanceBalanced upgrade. Optimizes for speed and responsiveness. Good for systems that can handle a bit more disruption for a performance gain.Medium
Extended OperationSelective upgrade for stability and security without aggressive modernization. Extends the system lifecycle with long-term support. Good when you want the system stable but aren't ready for full modernization.Low

The Modernization Advisor already suggested one profile. That card is highlighted. But you can try running a simulation on any profile to see what would happen.

Run a simulation​

Before applying an upgrade, run a simulation to check safety without modifying the system.

To run a simulation:

  1. Select Run it for me on the profile card.
  2. Wait for the simulation to complete (about 2 to 3 seconds).
  3. Review the Simulation Checkpoint results.

The Simulation Checkpoint shows four safety checks:

CheckWhat it verifies
Dependency compatibilityAll dependencies are compatible with the target profile.
Disk spaceSufficient disk space is available for the upgrade.
BackupA backup exists, or backup conditions are met.
Quirk conflictsNo known behavioral quirks conflict with this profile.

All four checks must pass for the simulation to clear the gate.

warning

The simulation must pass before the Apply buttons become active. This gate can't be bypassed.

If the simulation fails​

If one or more checks fail:

  • Switch to a less aggressive profile, for example Stable instead of Performance, and select Run it for me again.
  • Or return to the Modernization Advisor to choose a different upgrade path.

If the simulation fails, run a new scan and assessment to refresh the system's dependency data, then try again.

Apply the upgrade​

Once the simulation passes, the Apply [Profile] Profile button activates.

To apply the upgrade:

  1. Review the simulation checkpoint results.
  2. Select Apply Stable Profile, Apply Performance Profile, or Apply Extended Operation Profile on the card you want to apply.

NimbusWiz updates the profile status to [Profile] Profile Applied on that card.

Next step​

After applying a profile, start the deployment. See Deploy an upgrade.
