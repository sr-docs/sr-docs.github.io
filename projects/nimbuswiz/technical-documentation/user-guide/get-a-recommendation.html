Get a recommendation

After assessment, NimbusWiz recommends a specific path based on your system's dependencies, behavior, and your operational priorities.

The Modernization Advisor weighs three inputs to make this recommendation:

InputWhat it contributes
Assessment resultsWhich dependencies matter and which are at risk.
Quirk ProfileThe system's learned behavioral patterns: how it behaves under load, what has failed before, and where fragility exists.
Flight ProfileYour operational priority for this system: performance, stability, or efficiency.

This isn't a generic "upgrade" recommendation. It's tailored to this system, with this usage pattern, in your operational environment.

Before you begin​

To access the Modernization Advisor, your system must have a passing assessment. See Assess your system first.

Open the Modernization Advisor​

In the sidebar, select Modernization Advisor.

Read the recommendation​

The Modernization Advisor page has six sections.

Primary recommendation card​

At the top of the page, the primary recommendation card shows the Modernization Advisor's top recommendation with a confidence score.

Recommended: Performance Upgrade Confidence: 87%

The card also shows Affected Systems (the count of systems this recommendation applies to) and Expected Improvement (projected performance gain).

The confidence score reflects data completeness: multiple scans, full metadata, and a set Flight Profile earn higher scores. If it's below 60%, run additional scans or update the Flight Profile.

Override the recommendation​

If the recommendation doesn't fit your priorities, select Disagree with this recommendation? to open the override panel. The panel lets you select a different path and enter a reason. NimbusWiz saves the override and the reason to the audit log.

Decision Options Analysis​

The Decision Options Analysis shows all three paths forward as cards. Each card explains what the change would look like for this system, what it would cost (in risk and time), and what you'd gain.

OptionWhat it means
UpgradeModernize in place for maximum performance gain. Choose when dependencies are sound but the system needs a capability boost.
Partial ModernizationReplace only the components that are actually dragging the system down. Lowest risk. Makes sense when one or two dependencies are the problem, but the rest are stable.
Extended OperationUpgrade selectively for stability and security without aggressive modernization. Extends the system lifecycle with long-term support and a predictable maintenance schedule. Makes sense when you need the system stable but aren't ready for full modernization yet.
ReplaceThe system is too compromised for targeted fixes. A full replacement with a newer system makes more sense than trying to salvage this one.

Each option is evidence-based. A Partial Modernization recommendation means the assessment identified specific components at risk, not a generic suggestion to change something.

Risk vs. Performance Tradeoff​

The Risk vs. Performance Tradeoff section plots all three options on a scatter chart. Risk is on the x-axis, performance gain on the y-axis, so you can compare tradeoffs at a glance.

Why We Recommend This​

This section explains why NimbusWiz chose this recommendation. It lists the factors that mattered most for this system:

  • System Quirks: Behavioral patterns unique to this system (latency spikes, drift under load, failure conditions).
  • Dependency Risks: Which components are actually at risk of failure or incompatibility.
  • Usage Patterns: How this system is actually used in your environment.

Each factor shows how much weight it carried in the decision. If quirks weren't a factor for this system, that matters—it tells you the recommendation was based on dependency risk and usage, not on unusual system behavior.

System-Specific Recommendations​

The System-Specific Recommendations section shows a before-and-after comparison for each system. Projected metric changes (Stability, Performance, Network) are specific to each system's current state.

Adjust your flight profile​

The Flight Profile sets your operational priority and tells the Modernization Advisor what outcome matters most for this system. It is distinct from the Upgrade Profile you select on the Modernization page (Stable, Performance, or Extended Operation) which determines how the upgrade is executed.

The Flight Profile shapes the recommendation. The Upgrade Profile carries it out.

If the recommendation doesn't match your priorities, change the Flight Profile for a different result.

To adjust the Flight Profile:

  1. Go to the System Detail page for your system.
  2. In the Overview tab, change the Flight Profile selector to your preferred option.
  3. Return to the Modernization Advisor. The recommendation updates to reflect the new Flight Profile.

Next steps from the Modernization Advisor​

At the bottom of the page, the Next Steps section has three CTAs.

ButtonWhat it does
Apply RecommendationTakes you to the Upgrade Profiles page to select a profile and run a simulation.
Run SimulationOpens the simulation preview directly, without leaving the Modernization Advisor.
Review Risk AnalysisReturns you to the System Assessment page to review the full risk detail.

To follow the recommended path, select Apply Recommendation. To try a simulation before committing, select Run Simulation.

Next step​

Once you've chosen an upgrade path, configure and simulate the upgrade before applying it. See Modernize a system.
