Monitor system health

The change is deployed. NimbusWiz now monitors what happens. This page is where you confirm that the upgrade delivered what the assessment and simulation predicted, catch regressions before they become problems, and understand whether the system is now stable in its new configuration.

Open the Monitoring page​

In the sidebar, select Monitoring. The page is titled Monitoring & Alerts and shows health data for every system in your fleet.

Review system health metrics​

The Performance Metrics (24 Hours) chart tracks three core metrics for every system.

MetricWhat it measures
Stability IndexReliability and uptime consistency. Scored 0 to 100; higher scores indicate greater stability.
Responsiveness ScoreResponse time under normal and peak load. Scored 0 to 100; higher scores indicate faster, more consistent responses.
Network InteractionQuality and consistency of network communication. Scored 0 to 100; higher scores indicate cleaner network behavior.

Each metric appears as a line graph. The chart shows the past 24 hours of data with no time-range selector.

Read the trend line​

A rising trend line indicates improvement. A flat line indicates stability. A declining trend line, especially one that crosses into the amber or red zone, triggers a warning or critical alert automatically.

Review system resource usage​

The System Resource Usage chart shows CPU, Memory, and Disk utilization as area graphs over the same 24-hour window. Use it to identify resource pressure that may correlate with a declining Stability Index or Responsiveness Score.

Review alerts​

The Active Alerts section lists all active and recent alerts for your fleet. Alerts have three severity levels.

SeverityWhat it means
CriticalImmediate attention required. The system is degrading or has failed a key threshold. Shown with a red indicator.
WarningThe system is approaching a risk threshold. Action is recommended soon. Shown with an amber indicator.
InfoA notable event occurred. No immediate action required. Shown with a blue indicator.

To acknowledge an alert, select Acknowledge on the alert card. Acknowledging marks the alert as seen but doesn't resolve it. The alert stays visible until the underlying condition clears.

note

Acknowledge is a planned feature currently in progress.

To view the full alert history, select View All at the top of the Active Alerts section.

note

View All is a planned feature currently in progress.

Review predictive insights​

The Predictive Maintenance Insights section shows trend projections and suggested actions:

"Stability Index has declined 8 points over the past 5 days. Based on this system's historical drift pattern, further degradation is likely within 72 hours. Consider running a new scan."

Each insight card shows:

FieldDescription
MetricThe name of the metric being projected.
CurrentThe metric's current value.
Predicted (7d)The projected value seven days from now.
ConfidenceHow confident the prediction is, expressed as a percentage.
TrendImproving, Stable, or Declining.
RecommendationA plain-language action suggestion.

Predictive insights are advisory. They don't trigger automatic actions.

Anomaly detection​

NimbusWiz compares current system behavior against the baseline established during assessment and the patterns in the Quirk Profile. When behavior deviates significantly, NimbusWiz flags it and creates a Warning or Critical alert.

Anomalies link to the Troubleshooting page. When NimbusWiz identifies a likely cause, a View suggested fix link appears on the alert card.

System Modernized status​

When a system completes deployment and its monitoring metrics are consistently within healthy ranges, NimbusWiz marks it as System Modernized. This status appears as a badge on the Systems List and the Dashboard.

If a Critical alert is raised and metrics fall below healthy thresholds, the status reverts until the system stabilizes again.
