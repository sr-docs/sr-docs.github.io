What's NimbusWiz?​

NimbusWiz is a decision platform for preserving and modernizing legacy Nimbus2000-class systems. Rather than forcing immediate replacement, NimbusWiz helps you assess what you have, simulate upgrade outcomes, and choose the right path: upgrade, partial modernization, or replace.

The platform guides you through a six-stage pipeline: Register, Assess, Advise, Modernize, Deploy, Monitor.

What do I need before I start?​

Before logging in for the first time, have the following ready:

  • An Admin account, provisioned by your NimbusWiz administrator or through your organization's subscription.
  • System details for any systems you plan to register: a unique system ID in the format nimbus-[name], serial number, manufacturing year, current version, and location.
  • API keys for any integrations you want to set up later (such as GitHub, Datadog, and Slack). You can configure these after initial setup.

What does the Getting Started banner do?​

When you first open NimbusWiz, a Getting Started banner appears at the top of the Dashboard. The banner tracks four orientation steps as progress indicators:

  1. Connect a System: Register your first Nimbus system.
  2. Run Fleet Scan: Analyze system health and dependencies.
  3. View Recommendations: See intelligent upgrade suggestions.
  4. Apply or Preview: Deploy a safe profile, or run a simulation to preview the outcome.

To close the banner, select Dismiss. It reappears each session until you dismiss it.

For a full walkthrough, see Getting started in the User guide.

What's the difference between Demo Mode and my real data?​

Demo Mode fills NimbusWiz with pre-built dummy data: registered systems, scan results, deployment history, and monitoring metrics. Toggling Demo Mode on or off never affects your real systems or data. The two datasets are separate.

When Demo Mode is active, the sidebar button turns blue and shows "● Demo Mode Active." A blue banner also appears at the top of the page.

What are the three user roles?​

RoleWhat they can do
ViewerRead-only access to all screens. Can't take any actions.
OperatorFull access to system tasks: scans, upgrades, deployments, automation.
AdminEverything Operators can do, plus user management, API keys, integrations, audit logs, and settings.

Your current role appears in the Current Role badge at the bottom of the sidebar. To request a role change, contact your Admin.

How do I relaunch the Onboarding Tour?​

In the sidebar, select Start Product Tour. The tour highlights key areas of the interface and is available to all roles. You can relaunch it at any time.

How do I open the Glossary?​

In the sidebar header, select the ? icon. The Glossary modal opens from any screen without losing your current place.
