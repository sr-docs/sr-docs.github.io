Modernization Advisor

How does the Modernization Advisor work?​

The Modernization Advisor combines three inputs to generate a recommendation:

  1. Assessment results: The risk heatmap and dependency analysis from the most recent scan.
  2. Quirk Profile: Behavioral patterns NimbusWiz has learned about the system over time.
  3. Flight Profile: The operational priority you've set for the system.

From these inputs, the Modernization Advisor recommends Upgrade, Partial Modernization, or Replace (Nimbus2026), with a confidence score and a plain-language rationale.

What do the three recommendations mean?​

RecommendationWhat it means
UpgradeApply a full upgrade profile to modernize the system in place.
Partial ModernizationUpgrade specific components while preserving others. Lower risk, smaller performance gain.
Replace (Nimbus2026)The system is a candidate for full replacement with a Nimbus2026-class system.

What does the confidence score mean?​

The confidence score (0 to 100%) reflects how much data the Modernization Advisor has to work with. A higher score means the recommendation is based on more complete information.

ScoreInterpretation
80 to 100%High confidence: act on this recommendation.
60 to 79%Moderate confidence: consider running another scan first.
Below 60%Low confidence: the Modernization Advisor needs more data. Run additional scans or set a Flight Profile.

Should I always follow the Modernization Advisor's recommendation?​

Not necessarily. The recommendation is a starting point based on the available data, not a mandate.

Review the Risk vs. Performance Tradeoff chart and the Decision Options Analysis cards before deciding. The bottom of the page shows three CTAs: Apply Recommendation, Run Simulation, and Review Risk Analysis. Pick the one that matches your next action.

How do I override the recommendation?​

If the recommendation doesn't fit your priorities, select Disagree with this recommendation? to open the override panel. The panel lets you select a different path and enter a reason.

NimbusWiz saves the override and the reason to the audit log.

How do I improve a low confidence score?​

  • Run additional scans to give the Modernization Advisor more assessment data.
  • Set or update the Flight Profile on the System Detail page.
  • Allow NimbusWiz more time to learn behavioral patterns. Quirk Intelligence improves with each monitoring cycle.

Can I change the recommendation by changing the Flight Profile?​

Yes. The Flight Profile is one of the Modernization Advisor's three inputs. Switching from Stability-focused to Performance-focused, for example, may shift the recommendation from Partial Modernization to a full Upgrade.

To try a different profile, update it on the System Detail page and return to the Modernization Advisor. The recommendation updates to reflect the new Flight Profile.

note

The Flight Profile selector isn't interactive in the current prototype. The displayed value comes from the system's registration data.
