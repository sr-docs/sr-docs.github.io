System Health

How do I run a scan?​

In the sidebar, select System Assessment to open the assessment page directly. Run Scan buttons also appear on Fleet Management row actions and on the System Detail page header.

note

Run Scan is a planned feature currently in progress. The System Assessment page doesn't require you to trigger a scan from either of those locations first.

How long does a scan take?​

Scan duration depends on system complexity and the number of dependencies. Most scans complete within two to five minutes.

If you leave the page during an active scan, the scan continues in the background, but the progress indicator may reset. Return to the System Detail page to see current progress.

My scan failed. What do I do?​

Check the assessment results page for the specific failure reason. Common causes:

  • A network connectivity issue between NimbusWiz and the system.
  • A missing or inaccessible dependency.
  • An unsupported system configuration.

For guided fixes, see Troubleshoot issues. After resolving the blockers, run a new scan. Each scan creates a new record. Previous results are preserved in history.

What does the dependency graph show?​

The Dependency Graph shows every component in the system and how the components connect. Each node represents a component. The graph renders the system at the top level, direct dependencies at the next level, and nested dependencies below.

To see details for a specific component, select its node in the graph. A detail panel opens with the component name, version, and relationship to the system.

What does the risk heatmap table show?​

The Risk Heatmap & Recommendations table lists every component in five columns.

ColumnDescription
ComponentThe name of the dependency or system component.
Risk LevelHigh, Medium, or Low, shown with a color-coded badge.
Current VersionThe version currently installed on the system.
Recommended VersionThe version NimbusWiz recommends upgrading to.
RecommendationThe specific action NimbusWiz recommends for this component.

To sort the table, select a column header. High-risk components appear at the top by default.

What do the assessment summary stat cards show?​

Three stat cards at the top of the System Assessment page show a high-level risk summary.

CardWhat it counts
High Risk ComponentsComponents that block or significantly risk an upgrade.
Medium Risk ComponentsComponents that need attention but don't block the upgrade.
Up to Date ComponentsComponents that are compatible and require no action.

The full recommendation, with a confidence score, options comparison, and explanation, is on the Modernization Advisor page.

What does "Pass" or "Fail" mean at the assessment gate?​

Pass: No High-risk components remain unresolved. The Proceed to Modernization button is active.

Fail: One or more High-risk components block the upgrade path. Address the blockers in Troubleshooting before proceeding.

Can I view previous scan results?​

Yes. Each scan creates a new record in the system's history. To view previous results, open the System Detail page and select the Metrics or Logs tab.
